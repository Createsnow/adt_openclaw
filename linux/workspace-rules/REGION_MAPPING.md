# 提交人部门与区域映射

运行时副本已写入 `AGENTS.md`（会话开始注入）。Agent **禁止**再 `read` 本文件。改映射时必须同步 `AGENTS.md`。

## 现网默认

公开版企微通道 inbound **没有**已核验姓名、部门路径、大区、区域。OA 申请人只走 `requesterSenderId` 映射，与本节无关。

**没有已核验部门层级时：** 不要猜测大区和区域，需要地点则向员工确认。不要为此输出「未获取」页脚。下面的固定映射只在**本条消息实际附带**已核验部门层级时使用。

## 固定映射

1. 任一已核验部门层级名称包含“越南”（含 Vietnam / Việt Nam）时：
   - 大区：`越南`
   - 区域：`越南`
2. 非越南部门层级包含以下唯一关键词时：
   - `智园` → 大区 `深圳`，区域 `智园`
   - `大磡` → 大区 `深圳`，区域 `大磡`
   - `深汕` → 大区 `深圳`，区域 `深汕`
   - `光明` → 大区 `深圳`，区域 `光明`
   - `泗洪` → 大区 `深圳`，区域 `泗洪`
3. 其他已核验的非越南部门（没有上列园区关键词）：
   - 大区：`深圳`
   - 区域：`深圳`
4. 同一人员部门层级同时命中越南与深圳细分区域，或命中多个深圳细分区域（智园 / 大磡 / 深汕 / 光明 / 泗洪）时，映射状态为歧义，必须询问地点。

## 使用边界

- `大区` / `区域` 记录提交人的组织区域；员工在**本张未完结工单**明确说明故障发生地点时，故障地点以员工说明为准。问地点时为本张工单回序号也算已说明：`1` 智园、`2` 大磡、`3` 深汕、`4` 越南、`5` 光明、`6` 泗洪。已取消、已提交、其它会话或历史工单里的地点不算。
- 员工未说明地点时，**仅当本张工单已经按上文解析出区域**，才可用它缩小带地点的所属系统；只有当前工单类型确实存在同名地点选项时才能自动选择。不得把上一张单的园区带到新单。
- 电脑/打印机/网络问题**没有**「深圳」这一项：
  - 区域 `智园` → `电脑/打印机/网络问题（智园）`
  - 区域 `大磡` / `深汕` / `光明` / `泗洪` / `越南` → 对应同名选项
  - 区域仅为 `深圳`、映射歧义、或尚未解析时，必须请员工确认，不得自动改成（深汕）或（智园）
- 「邮箱系统（国内） / 邮箱系统（越南）」「文件管理系统（国内） / 文件管理系统（越南）」同样：没有已解析区域时列出候选，不要默认国内项。
- `MES系统（越南B部）` 与 `MES系统（越南C部）` 不是同一项。区域为 `越南` 且员工只说 MES、未说 B 部或 C 部时，必须列出这两项请员工选，不得默认任一项。
- 区域映射不得改写 `ROUTING_RULES.md` 中的建议责任人。
