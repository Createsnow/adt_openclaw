# 工单分类与系统清单

版本：`2026-09-07-oa-workspace-mapping-v4`

运行时副本已写入 `AGENTS.md`（会话开始注入）。Agent **禁止**再 `read` 本文件。改系统名或建议责任人时必须同步 `AGENTS.md`。

编辑权威是本文件 + `MAPPING_RULES.md`，须与 `AGENTS.md` 一致。多个人名表示全部建议责任人，只作员工可见「处理人」；模型不要传人员 id。插件按所属系统写入 OA `clry`（附录负责人 id）。

下表是**运维支持全集**。传给 `oa_workflow` 的 `systemName` 必须属于**当前工单类型**允许的系统，插件会拒绝非法组合。

- **运维支持**：下表全部。
- **权限申请**：下表全部，但**没有**电脑/打印机/网络问题（各地点）、OA开发支持、ERP开发支持、北森招聘系统。
- **IT需求**：下表全部，但**没有**「邮箱系统（国内）」、电脑/打印机/网络问题（各地点）、OA开发支持、ERP开发支持、北森招聘系统。

电脑/打印机/网络问题的地点选项是智园 / 大磡 / 深汕 / 越南 / 光明 / 泗洪，**没有**「深圳」；问员工时用固定 1–6。区域 `智园` 用 `电脑/打印机/网络问题（智园）`；区域仅为 `深圳` 或尚未解析时不要自动改成（深汕）或（智园）。`MES系统（越南B部）` 与 `MES系统（越南C部）` 不是同一项：员工未明确说 B 部或 C 部时不得默认任一项。

## 待人工确认

以下情况不得自动匹配、不得 `prepare`：

- 员工没有确认工单类型，或类型无法唯一判断。
- 所属系统不在对应类型列表中。
- 员工一次描述多个系统且无法判断主系统。
- 无已核验部门且**本张工单**员工未说明地点，却需要带地点的系统（上一张单的园区不算）。
- 只说 MES / 越南、未明确「越南B部 / B部」或「越南C部 / C部」时，不得在 `MES系统（越南B部）` 与 `MES系统（越南C部）` 之间默认任一项。
